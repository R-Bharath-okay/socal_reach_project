# socal_reach_project
📱 Social Media Reach Analysis

📌 Project Overview

This project focuses on analyzing social media post performance and audience reach to identify trends, engagement patterns, and factors that contribute to better-performing content.

The project was completed as part of my Data Analyst Internship and demonstrates practical skills in data cleaning, analysis, visualization, and extracting meaningful insights from social media data.

🎯 Objectives

- Analyze social media post performance
- Understand reach and engagement patterns
- Identify high-performing content
- Compare post performance across different categories
- Analyze audience interaction
- Identify trends that can improve social media performance
- Create a visual summary of the analysis

🛠️ Tools & Technologies

- Microsoft Excel
- Data Cleaning
- Data Analysis
- Pivot Tables
- Charts & Visualizations
- Statistical Analysis

📂 Dataset

The project contains social media post-level data with 600+ records.

Sheets Included

1. Posts

- Contains the detailed social media post data
- Used as the primary dataset for analysis

2. Summary

- Contains summarized analysis
- Includes calculated metrics and visualizations
- Provides an overview of social media performance

📊 Dashboard

The project includes an Excel dashboard that provides a visual overview of social media reach and performance.

"Social Media Reach Dashboard" (social_dashboard.png)

🔍 Analysis Performed

The analysis covers:

- Post reach
- Engagement performance
- Post-level comparisons
- Content performance trends
- High-performing posts
- Overall social media performance
- Relationship between different performance metrics

💡 Key Insights

The analysis helps identify:

- Which posts generate higher reach
- Which content performs better
- Patterns in audience engagement
- High-performing and low-performing posts
- Opportunities to improve social media content strategy
